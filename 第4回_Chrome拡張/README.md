# Chrome拡張：欲しいものだけ入れてください

畠山式AI税理士ブートキャンプで配布している Chrome拡張です。
freee会計・マネーフォワード クラウド会計の画面に、勘定科目ボタンやBS残高のドロワーを重ねて表示します。

**全部入れる必要はありません。使うソフトに合うものだけで大丈夫です。**

## freee会計を使っている人

| フォルダ | できること |
|----------|-----------|
| `freee-kamoku-buttons/` | 「自動で経理」「取引・口座振替[β版]」画面に**勘定科目ボタンパネル**を表示。クリックで科目を入力・確定 |
| `freee-bs-drawer/` | 試算表・自動で経理の画面の右側に、**BS残高（営業債権・営業債務・預り金）をスライド表示**。科目行を開くと補助・品目別の内訳、取引行を開くと元となった明細まで確認できる |

freeeの帳簿点検には、智原翔悟先生（ENJOINT）が公開している **「freee帳簿拡張」** があります。
こちらはChromeウェブストアで公開されているので、リンクから1クリックで入ります（本リポジトリでは配布していません）。

https://chromewebstore.google.com/detail/lcckhenfjalkkpdkopljocoibkpgejca

## マネーフォワード クラウド会計を使っている人

| フォルダ | できること |
|----------|-----------|
| `mf-bulk-select-extension/` | **MF会計アシスト**。ルール一致明細の一括チェック＋勘定科目ボタンパネル＋補助科目・取引先のワンクリック追加 |
| `mf-bs-drawer/` | 「連携サービスから入力」画面の右側に、**BS残高をスライド表示**（freee版のMF対応版） |
| `mf-chobo-extension/` | **帳簿点検ハイライト**。総勘定元帳・補助元帳・残高試算表で、マイナス金額・未選択の補助科目・怪しい税区分・仮払金の高額計上などを自動で色づけ |

`freee-kamoku-buttons/` と `mf-bulk-select-extension/` は「🔍 何費？検索」（勘定科目辞典を小窓で開く機能）も備えています。

## 入れ方（共通の流れ）

1. Chromeで `chrome://extensions` を開く（Braveは `brave://extensions`）
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. 入れたい拡張のフォルダを選ぶ

**細かい手順と使い方は、各フォルダの `README.md` を読んでください。**
うまく入らないときは、画面のスクリーンショットをClaude Codeに貼って相談すれば案内してくれます。

> フォルダ名が英語のままなのは、Chromeに読み込ませるときに日本語のフォルダ名がトラブルの原因になることがあるためです。変更しないでください。

## 注意

- BSドロワーと帳簿点検ハイライトは**読み取り（GET）専用**です。freee・MFへの書き込みは一切行いません。
- 科目ボタンの拡張は**入力を助けるだけ**で、勘定科目を自動で判断するものではありません。何を選ぶかは今までどおりご自身で決めてください。
- 帳簿点検ハイライトが色をつけるのは「見るべき行の目印」です。**指摘＝誤りではありません**。中身の判断はご自身でお願いします。
- 拡張は各ソフトの画面構成に合わせて作ってあります。ソフト側の画面が変わると動かなくなることがあります。その場合は講義でお知らせします。
