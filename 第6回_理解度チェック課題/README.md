## 課題①：記帳の自動化

第3回の「勘定科目ルール.md」と同じフォルダに `課題1_未処理明細.csv` を置いて、
Claudeに次の指示を貼ってください。

```
課題1_未処理明細.csv を読み込み、勘定科目ルール.md のルールに従って200件すべてを分類してください。
出力は表形式で「日付／摘要／金額／勘定科目／判定元（ルール・AI・要確認）／理由」の6列にし、
件数が多いので、判定元ごとの件数サマリも最後に付けてください。
NGキーワードに当たる明細は、どのキーワードに当たったかも書いてください。
分類が終わったら、判定元が「AI」になった明細について、勘定科目ルール.md のルール表に追加する行の案を出してください。
```

優先順位・金額の切替・NGキーワードのひっかけを20件以上混ぜてあります。
「即決してよい明細」と「人が確認すべき明細」を分けられるかがポイントです。

## 課題②：仕訳チェックの自動化

この帳簿には**わざと誤りを14件**仕込んであります。
第5回の「レビュー観点表」（スキル化した方はご自身のスキル）を使って、AIにレビューさせてください。

```
課題2_会社プロファイル.md を読んで会社の前提を把握したうえで、
課題2_仕訳帳.csv・課題2_残高試算表.csv・課題2_月次推移表.csv を、
レビュー観点表.md の観点でレビューしてください。
月次推移表は毎月の定期性（毎月あるはずのものが無い月・急に跳ねた月）の確認に使ってください。
気づいた点を「観点ID／内容／なぜ問題か／要訂正・要確認・正常のどれか」の表にまとめてください。
```

### 注意（ここが本題です）

AIの指摘を鵜呑みにしないでください。
**「一見異常に見えるけれど、この会社では正常」というものも3つ**入れてあります。
どれが本当の誤りで、どれが正常かを決めるのは皆さんです。プロファイルをよく読んでください。

## 発展課題（任意）：freeeテスト事業所への登録

課題①の分類結果を、実際にfreeeへ登録するところまで体験したい方向けのおまけ課題です。
第3回のセットアップ（`.env` と `token.json`）が済んでいることが前提です。

**手順**

1. freeeで**課題用のテスト事業所を新しく作成**します（本番の事業所は絶対に使わないでください）
2. `.env` の `FREEE_COMPANY_ID` を、作成したテスト事業所のIDに書き換えます（IDの調べ方は第3回READMEの「事業所IDがわからない場合」参照）
3. Claudeに次の指示を貼ってください

```
まずfreee APIで接続中の事業所名を取得して表示し、わたしが「OK」と言うまで登録しないでください。
OKと言ったら、課題1の分類結果のうち判定元が「ルール」の明細から10件だけを、
freee APIでこの事業所に取引（支出）として登録してください。
登録後、登録できた件数と、freeeのどの画面で確認できるかを教えてください。
```

4. freeeの「取引」画面で、登録された10件を自分の目で確認します

**必ず守ること**

- 登録前に表示された事業所名が**テスト事業所であることを自分の目で確認**してから「OK」と言ってください（顧問先の本番事業所に登録してしまう事故を防ぐためです）
- 終わったら `.env` の `FREEE_COMPANY_ID` を**元の値に戻してください**

「分類 → 承認 → 登録」の一連の流れを自分の手で回すことが目的です。
