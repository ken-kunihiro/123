# Claude Code セットアップ一式（はじめにこれを読んでください）

このフォルダ（`.claude`）には、Claude Code に「あなた専用の働き方」を覚えさせるための設定一式が入っています。
**このREADMEだけ最初に読めば、あとは全部 Claude Code に道案内させながら進められます。**

> 💡 この `README.md` を含む `.md` ファイルは、すべて **Claude Code のデスクトップアプリの中で開いて読めます**。別のエディタを用意する必要はありません。ファイルをドラッグ＆ドロップするか、「このREADMEを読んで」とClaudeに頼んでください。

> 📁 **`.claude` は隠しフォルダです。** エクスプローラー／Finderで見えないときは「隠しファイルを表示」をONにしてください。見つからなくても、Claude Codeに「.claudeフォルダの中身を見せて」と頼めば大丈夫です。

---

## 📦 入っているもの（4点セット）

このフォルダは、**あなたのPCの `.claude` フォルダにそのまま置ける形**にしてあります。中身は次のとおりです。

```
.claude/
├── README.md                          ← いまこれ。全体の地図
├── docs/                              4点セットの手順書（読むところ）
│   ├── 1_CLAUDE.mdとrules.md          ① キャラ設定・事務所ルール
│   ├── 2_セキュリティ.md               ② うっかり事故防止のロック
│   ├── 3_メモリ.md                     ③ セッションを跨いで覚えておくメモ帳
│   ├── 4_Hooks.md                      ④ 長い会話でも前提を忘れない仕掛け
│   └── SECURITY-DESIGN.md             ②の設計の考え方（興味があれば）
│
├── CLAUDE.md.template                 ①で使う：事務所ルールのひな形
├── rules/                             ①で使う：persona.md.template（キャラ）・context7.md.template
├── settings.security.template.json    ②で使う：設定に足す断片
├── .gitignore.template                ②で使う：秘密情報の除外設定のひな形
├── setup.sh / test-guards.sh          ②で使う：設置スクリプトと動作確認
├── hooks/                             ②④で使う：ガード3本＋session-start / post-compact
├── memory/                            ③で使う：MEMORY.mdと4種類のテンプレート
│
└── skills/    ※ここだけ第3回のキット用（第1回の4点セットとは無関係）
```

手順書は `docs/` の**①→②→③→④の順番**で進めるのがおすすめです。後の番号ほど、前の番号の設置物（特にCLAUDE.mdと`.claude`フォルダ）を前提にしているからです。

> ⚠️ **`skills/` だけは性格が違います。** ここは第3回「freeeオート経理（体験版）」の手順書とプログラムが入った場所で、このキットのフォルダを開いたときだけ使うものです。**このフォルダを丸ごと自分のPCの `.claude` にコピーするのはやめて、下の手順どおり、必要なものだけ設置してください。**

---

## ✅ 始める前の前提条件

- **Claude Code（デスクトップアプリ or CLI）がすでにインストールされていること**
  - まだの方は、先に Claude Code 本体のセットアップを済ませてください（講座の別案内を参照）
  - インストール済みかどうか不安なら、Claude Code を開いて「こんにちは」と話しかけてみて、返事が来ればOKです
- **（Windowsの方）Git と Python が入っていること**
  - ②セキュリティと④Hooksは、Gitに付属する **Git Bash** と **Python** を使います
  - まだの方は [git-scm.com](https://git-scm.com/) と [python.org](https://www.python.org/) からインストールしてください（画面に沿って進めるだけでOK。迷ったらClaudeに「GitとPythonのインストールを案内して」と頼めば道案内してくれます）
  - Macの方は標準搭載なので、追加インストールは基本的に不要です

## 🤖 一番ラクな進め方：Claude Code に丸ごと渡す

このキットのフォルダを Claude Code で開いた状態で、次の文章をそのままコピペしてください。

```
このフォルダの .claude/ には、Claude Codeのセットアップ一式（4点セット）が入っています。
.claude/README.md を読んで、docs/ の順番（①md→②セキュリティ→③メモリ→④Hooks）の通りに、
私のPCへの設置を進めてください。

私は{{税理士／会計士／社労士／行政書士／弁護士／その他}}で、
事務所名は「{{あなたの事務所名}}」です。

進め方のルール：
- docs/ の各手順書に書いてある内容に沿って進めてください
- .claude/skills/ は第3回のキット専用なので、私のPCの .claude にはコピーしないでください
- カスタマイズに必要な情報（名前・呼び方・キャラの性格など）は、その都度1問ずつ私に聞いてください
- settings.json など既存の設定ファイルを変更する前に、必ず日付つきのバックアップコピー（例: settings.json.bak_YYYYMMDD）を作ってください
- 既存ファイルの上書き・バックアップなど、確認が必要な場面では必ず先に私に確認してください
- 1つ終わったら、「①が終わりました。②に進みますか？」のように区切って報告してください
- 全部終わったら、最後に「動作確認の手順」を案内してください
```

これを送ると、Claude Code が①〜④を順番に、必要な質問をしながら設置を進めてくれます。**「コードが分からないから無理」と思う必要はありません。** わからない言葉が出てきたら、その場で「それって何？」と聞き返して大丈夫です。

> 💡 一気に4つ全部はちょっと不安、という方は、「まずは①だけ進めてください」のように1個ずつ区切ってお願いしてもOKです。

## 🗺️ 各手順書で何が起きるか（全体像）

| 順番 | 手順書 | 何をする | 使うファイル | 所要時間目安 |
|------|-------|---------|-------------|-------------|
| ① | `docs/1_CLAUDE.mdとrules.md` | AIの名前・性格と、事務所のルールを設定 | `CLAUDE.md.template` / `rules/` | 20〜30分 |
| ② | `docs/2_セキュリティ.md` | `.env`の誤読み取り・外部送信・`rm -rf`事故を防ぐロックを設置 | `setup.sh` / `hooks/*-guard.sh` / `settings.security.template.json` / `.gitignore.template` | 20〜30分 |
| ③ | `docs/3_メモリ.md` | 「前にも言いましたよね」を実現するメモ帳の仕組みを設置 | `memory/` | 15〜30分 |
| ④ | `docs/4_Hooks.md` | 長い会話・圧縮後も前提を忘れない仕掛けを設置 | `hooks/session-start.sh` / `hooks/post-compact.sh` | 10〜15分 |

合計 **1〜1.5時間程度**（Claudeに任せれば実質の手作業はもっと短いです）。一度に終わらせる必要はなく、何回かに分けて進めて構いません。

### ① CLAUDE.mdとrules（最初にやる理由）

AIの性格（`rules/persona.md.template`）と事務所のルール（`CLAUDE.md.template`）を決めるところです。ここで作る `.claude` フォルダに、②③④が設置物を追加していくので、必ず最初にやってください。

> `.template` が付いたファイルは、**コピー先で `.template` を外してリネーム**して使います（`CLAUDE.md.template` → `CLAUDE.md`、`persona.md.template` → `persona.md`）。キットの中で `.template` を付けてあるのは、**書き換える前の空欄だらけのひな形が、このキットのルールとして読み込まれてしまうのを防ぐため**です。

### ② セキュリティ（次にやる理由）

①で `.claude/settings.json` がまだ無ければここで作られます。顧客の機微情報を扱う前に、最初に「事故防止のロック」をかけておくのが安全だからです。

### ③ メモリ（その次の理由）

①②が終わって「事務所の憲法」と「ロック」が整った状態で、③の「動く事実を覚えるメモ帳」を足します。CLAUDE.mdと役割が混ざらないよう、①の後に学ぶのがおすすめです。

### ④ Hooks（最後の理由）

④は①〜③で設置した `CLAUDE.md` の内容を、長い会話でも自動で思い出させる仕掛けです。①が無いと注入する中身が無いので、最後にやります。

## 🙋 自分の手で1つずつ進めたい人へ

Claudeに丸投げせず、自分でやりたい場合は、`docs/` の中の手順書を順番に開いて、書いてある手順をそのまま実行してください。どの手順書にも「Mac の場合 / Windows の場合」の手順と、「困ったらこのプロンプトをClaudeに渡してください」という丸投げ用文章が用意されています。

1. `docs/1_CLAUDE.mdとrules.md` を開く
2. `docs/2_セキュリティ.md` を開く
3. `docs/3_メモリ.md` を開く
4. `docs/4_Hooks.md` を開く

---

## ✅ 全部終わったあとの動作確認（3つ聞いてみる）

1. 「私の名前を呼んでみて」 → ①で設定したキャラ・呼び方で返ってくればOK
2. 「`.env` ファイルを読んで」 → ②のロックで確認・ブロックされればOK
   - ※ 作業フォルダに `.env` が無いと「ファイルがありません」で終わってしまいます。先に「中身が `TEST=1` だけのダミーの `.env` ファイルをこのフォルダに作って」と頼んでから試してください
3. 「私のメモリ一覧を教えて」 → ③で書いたメモリが出てくればOK（まだ何も書いていなければ「メモリはまだありません」でOK）

すべて反応が返ってくれば、4点セットの設置は完了です。

## ⚠️ よくあるつまずき

| 症状 | 原因・対処 |
|------|-----------|
| 設定したのに反映されない | Claude Code を**完全に再起動**したか確認（タスクトレイに残ってないかも確認） |
| `.claude` フォルダが見つからない | 隠しフォルダなので「隠しファイルを表示」をON。一度Claude Codeを起動すると自動で作られます |
| ファイル名が `〜.md.txt` になっている | 拡張子が見えない設定のままリネームすると起きがちです。エクスプローラー／Finderで拡張子表示をONにして確認 |
| JSONがエラーになる | カンマ・カッコの数を確認するか、その場でClaudeに「このエラー直して」と貼り付ければOK |
| ZIP解凍したら `.claude` が消えた／文字化けした | 隠しフォルダなので見えていないだけのことが多いです。「隠しファイルを表示」をON。フォルダ名が化けている場合は7-Zip等で解凍し直すか、Claudeに「このフォルダの中身を確認して、READMEの順に進めて」と頼めば進められます |
| settings.json を触ったら Claude Code がおかしくなった | 変更前のバックアップ（settings.json.bak 等）を元のファイル名に戻せば復旧。分からなければエラーメッセージごとClaudeに貼り付ける |
| hooks を設置したのに反応しない | Claudeに「hooksファイルの実行権限と改行コード（CRLF/LF）を確認して直して」と頼む。ZIP・ドライブ経由のファイルで起きがちです |
| 書いたはずのメモリが読まれない | メモリは「Claude Codeで開いたフォルダ」ごとに保存されます。設置したときと同じフォルダを開き直してください |

---

## 💬 困ったとき

手順の途中でも、エラーが出ても、遠慮なくその場で Claude Code に聞いてください。「こんな初歩的なこと聞いて大丈夫？」と思う必要は一切ないです。それでも分からなければ、ブートキャンプ内で気軽に聞いてくださいね。
