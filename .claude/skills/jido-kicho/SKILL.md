# 体験①：自動記帳の案内

## 判定の考え方（先に読む）

勘定科目の判定基準は `第3回_freeeオート経理/勘定科目ルール.md` に書いてあります。
**仕分けの相談・科目の質問を受けたら、まずこのファイルを読んでから答えてください。**
判定順（NGキーワード → ルール表 → AI判定）と、自動登録しないキーワードの一覧が入っています。

## 流れ（必ずこの順番）

### 1. まず「見るだけ」実行

キットの一番上のフォルダを作業場所にして：

```
python .claude/skills/jido-kicho/auto_keiri.py
```

- 未処理の出金明細を最大5件取得し、2段階（rules.csv → AI）で仕分けして一覧表示する
- この段階では**何も登録されない**ことを受講生に伝えて安心してもらう
- 結果は `第3回_freeeオート経理/result.csv` にも保存される（Excelで開ける）

### 2. 結果を一緒に読む

一覧の見方を説明する：

- **明細ID**: 登録時に指定する番号
- **判定**: 「登録候補」＝承認すれば登録可 / 「要確認」＝人が見るべき / 「要確認（スキップ）」＝給与・税金・借入等で自動登録しない
- **判定元**: 「ルール」＝rules.csvで一致 / 「AI」＝Claudeが判定

勘定科目の候補について質問されたら、理由の説明にとどめる。**正しいかどうかの税務判断はせず**、迷うものは講師（畠山）に確認するよう案内する。

### 3. 承認 → 登録

受講生が「この明細は登録してよい」と**明細IDを特定して承認した場合のみ**：

```
python .claude/skills/jido-kicho/auto_keiri.py --register --ids 123,456
```

- 承認されていないIDを勝手に足さない
- 「全部登録して」と言われても、1件ずつ金額・内容を確認してもらってから実行する

### 4. 登録後の後片付け（必ず案内）

freeeには消込APIがないため、登録しても「自動で経理」画面に元の明細が未処理のまま残る。
**freeeの画面で該当明細を「無視」にするか、手動で今登録した取引に紐づける**よう必ず案内する。放置すると二重計上の原因になる。

## 応用（余裕がある受講生向け）

- `--limit 3` で件数変更
- `.claude/skills/jido-kicho/rules.csv` をExcelで開いて、自社によく出るキーワードを追加してもらう（「ルールを育てるほど速く・安く・正確になる」体験）
- 育て方の考え方は `第3回_freeeオート経理/勘定科目ルール.md` の「このルール表の育て方」に書いてある
