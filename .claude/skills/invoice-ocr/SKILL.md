# 体験②：請求書OCRの案内

## 流れ（必ずこの順番）

### 1. PDFを置いてもらう

`第3回_freeeオート経理/請求書PDFを置く場所/` フォルダに請求書PDFを置いてもらう（何枚でもOK）。
受講生が「デスクトップにある」等と言ったら、**代わりにこのフォルダへコピーしてあげる**。
テスト用なら、金額の小さい・内容が単純な請求書から始めるよう勧める。

### 2. まず「読み取るだけ」実行

キットの一番上のフォルダを作業場所にして：

```
python .claude/skills/invoice-ocr/invoice_ocr.py
```

- 各PDFの取引先名・請求日・支払期日・税込金額・内容の要約・勘定科目の候補・源泉所得税の対象らしさを一覧表示する
- この段階では**何も登録されない**ことを伝える
- 結果は `第3回_freeeオート経理/invoice_result.csv` にも保存される

### 3. 結果を一緒に確認する

- **金額と日付は必ず原本PDFと突き合わせて**もらう（OCRは読み間違えることがある）
- 源泉所得税「対象かも」と出た請求書は、体験版では自動計算しないため、扱いを講師（畠山）に確認するよう案内する
- 勘定科目の候補は理由の説明にとどめ、**税務判断はしない**

### 4. 承認 → 1枚だけ登録

受講生が内容（特に金額・日付）を確認して承認した場合のみ：

```
python .claude/skills/invoice-ocr/invoice_ocr.py --register --file 請求書A.pdf
```

- ファイル名を特定して承認されたものだけ登録する
- 複数枚を一括では登録しない（1枚ずつ確認→登録）

## 注意

- 読み取り精度が低いPDF（手書き・かすれ・写真）は「要手入力」と正直に伝える
- 登録後の取引はfreeeの取引一覧で確認できることを案内する
