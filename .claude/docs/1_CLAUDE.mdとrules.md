# Claude 設定ファイル雛形セット（ブートキャンプ配布版）

キットの `.claude/` フォルダに入っているのは、Claude Code（Claude のデスクトップ／CLI アプリ）に
「あなた専用の働き方」を覚えさせるための **設定ファイルの雛形** です。

`< >` で囲った部分を自分の事務所・自分用に書き換えるだけで使えます。
（例：`<あなたの名前>` → `山田太郎`）

---

## 📦 入っているファイル

```
.claude/
├── docs/1_CLAUDE.mdとrules.md  ← いまこれ。置き場所の説明書
├── CLAUDE.md.template          ← 「この案件・この事務所のルール」を書く指示書
└── rules/
    ├── persona.md.template     ← AI の名前・性格・口調（キャラ設定）
    └── context7.md.template    ← 「ライブラリは最新ドキュメントを見てね」ルール
```

> **どのファイルも、コピーしたあとに末尾の `.template` を外してリネーム**して使います。
> （`CLAUDE.md.template` → `CLAUDE.md`、`persona.md.template` → `persona.md`）
>
> キットの中で `.template` を付けてあるのは、**書き換える前の空欄だらけのひな形が、このキットを開いたときのルールとして読み込まれてしまうのを防ぐため**です。中身が `<AI に付けたい名前>` のままでは、Claude が困ってしまいますからね。

ファイルは2種類あります。役割が違うので、置く場所も違います。

| 種類 | 何のため？ | いつ効く？ |
|---|---|---|
| **グローバルルール**（`rules/` の中身） | AI の性格・口調・いつも守ってほしい個人設定 | **毎回・すべての作業で自動的に** |
| **CLAUDE.md** | 「この事務所・この案件ではこうして」という業務マニュアル | **そのフォルダで作業するときだけ** |

ざっくり言うと…
- **グローバルルール = AI（あなたの分身）の "性格・クセ"**
- **CLAUDE.md = その現場の "業務マニュアル"**

---

## 🗂️ 置き場所（ここが一番大事！）

### ① グローバルルール（`rules/` フォルダの中身）

すべての作業で自動的に読み込まれる、いわば「常時オン」の設定です。
下のフォルダに `persona.md.template` と `context7.md.template` をコピーし、**末尾の `.template` を外して** `persona.md` / `context7.md` にリネームしてください。

**Windows の場合**
```
C:\Users\<あなたのユーザー名>\.claude\rules\
```

**Mac の場合**
```
/Users/<あなたのユーザー名>/.claude/rules/
```

> 💡 `.claude` フォルダが見つからないときは、一度 Claude Code を起動すると自動で作られます。
> 先頭がドット（`.`）のフォルダは隠しフォルダなので、表示設定で「隠しファイルを表示」をオンにしてね。

### ② CLAUDE.md（`CLAUDE.md.template` をリネームして使う）

「事務所ごと」「案件ごと」に置く指示書です。
作業したいフォルダ（例：顧問先ごとのフォルダ）の **直下** に `CLAUDE.md` を置くと、
Claude がそのフォルダで作業するときだけ自動で読み込みます。

```
<作業フォルダ>\
└── CLAUDE.md   ← ここに置く
```

> 💡 「全プロジェクト共通で効かせたい指示」なら、`.claude\CLAUDE.md`（グローバル）に置く手もあります。
> まずは「案件フォルダごとに置く」から始めるのがおすすめ。

---

## 🚀 使い方（3ステップ）

1. **コピー**：上の置き場所に、それぞれのファイルをコピーする（`CLAUDE.md.template` は `CLAUDE.md` にリネーム）
2. **書き換え**：ファイルを開いて `< >` の部分を自分用に直す
3. **再起動**：Claude Code を開き直すと、新しい設定が反映される

これだけ！あとは普通に話しかければ、設定どおりに動いてくれます。

---

## ⚠️ ちょっとした注意

- **個人情報・パスワード・口座番号などは書かない。** 設定ファイルは毎回読み込まれるので、機密情報は入れないこと。
- **最初は欲張らない。** いきなり全部書かず、「名前と口調だけ」から始めて、慣れたら足していくのがコツ。
- **困ったら消せばOK。** 設定がおかしくなったら、そのファイルを消すか中身を空にすれば元に戻ります。

わからないことがあれば、ブートキャンプで気軽に聞いてくださいね！
