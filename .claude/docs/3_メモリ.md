# Memory（セッションを跨いで覚えておくメモ帳）

CLAUDE.md が「事務所の憲法（不変のルール）」だとすると、Memory は「**動く事実**」を残す場所です。
- 「このフォルダ命名はこう、って前にも言ったでしょ？」
- 「この顧客の決算月、毎回聞かれてる気がする…」
- 「またゼロから自分の経歴を説明してる…」

これを type 別の小さなファイルに分けて積み上げると、Claude が起動時に索引（`MEMORY.md`）を読んで、「あ、その話前にもしましたよね」と言えるようになります。

---

## 入っているファイル

```
.claude/
├── docs/3_メモリ.md        ← いまこれ
└── memory/
    ├── template_user.md       ← あなたの属性・経歴・恒常的な好み用
    ├── template_feedback.md   ← 「こう動いて」という指示用
    ├── template_project.md    ← 進行中の仕事・案件の進捗用
    ├── template_reference.md  ← 外部リソース（URL・ID）へのポインタ用
    └── MEMORY.md.template     ← 索引ファイルのひな形
```

---

## CLAUDE.md との使い分け（結論1行）

| ファイル | 役割 | 例 |
|---------|------|-----|
| **CLAUDE.md** | 不変のルール・憲法 | 「税務判断しない」「フォントはメイリオUI」 |
| **Memory** | 動く事実・覚えておきたい個別事項 | 「A社案件は5/15が締切」「あの提案書のリンク」 |

全部 CLAUDE.md に書くと、①ファイルが膨れて重要ルールが埋もれる ②終わった案件が消されずに残り続ける ③「必要なときだけ」呼び出せない、という問題が起きます。だから分けます。

---

## 4つの type

| type | 何を書く？ | 書かなくていいもの |
|------|-----------|------|
| **user** | あなたの属性・経歴・恒常的な好み | 名前・事務所名（CLAUDE.mdに書けばOK） |
| **feedback** | Claude への働き方の指示・修正。**Why と How to apply は必須** | 一度きりの軽い修正 |
| **project** | 進行中の仕事・案件の進捗。相対日付は絶対日付に変換 | 終わった案件（消すかアーカイブへ） |
| **reference** | URL・Notion DB ID・ダッシュボードリンク等 | 1回しか使わないURL |

> 💡 迷ったら **feedback** と **reference** から書き始めるのがおすすめです。
> feedback は「同じ注意を2回したら書く」、reference は「あのリンクどこだっけ」をなくす、と覚えてください。

---

## 置き場所

```
[ホームフォルダ]/.claude/projects/<プロジェクトslug>/memory/
```

「プロジェクトslug」は、Claude Code を起動した作業フォルダを記号化したもの（例：`C--Users-yamada-Documents-work`）。わからなければ Claude にこう聞いてください。

> 「私のこのプロジェクトのメモリフォルダのフルパスを教えて」

---

## 使い方（3ステップ）

1. **コピー**：書きたい type のテンプレートをコピーして、上の置き場所に保存
2. **書き換え**：ファイル名を `<type>_<内容を表す名前>.md`（例：`feedback_proposal_discount.md`）にして、`< >` の中身を埋める
3. **索引に追加**：`MEMORY.md.template` を `MEMORY.md` としてメモリフォルダ直下に置き、1行ポインタを追記

最初は **3件** で十分です。type ごとに1件ずつ、一番「いつも言ってるな」と思うことから書いてみてください。

---

## 🤖 自分で書くのが面倒な人へ

Claude Code 自身に頼んでもOKです。

```
このREADMEと4つのテンプレートを渡します。
私の最初のメモリを3つ書きたいです（user 1件 / feedback 1件 / reference 1件）。

私への質問を1問ずつ投げてください。
最後に、書き上がった3ファイルと、索引用の MEMORY.md を提示してください。
```

---

## 動作確認

Claude Code を再起動してから、チャット欄で聞いてみてください。

> 「私のメモリ一覧を教えて。type別に整理してくれる？」

→ 書いたメモリが type別に出てくれば成功です。

---

## ⚠️ ちょっとした注意

- **メモリは「Claude Code で開いたフォルダ」ごとに保存されます。** 別のフォルダで Claude Code を開くと、そのメモリは読まれません（消えたわけではありません）。「メモリが読まれない？」と思ったら、設置したときと同じフォルダを開き直してください。
- **顧客名・金額くらいはOKですが、マイナンバー・口座番号・パスワードは書かない。** Memoryもローカルファイルですが、会話のコンテキストとして送信される性質上、機密情報は避けてください。
- **索引（`MEMORY.md`）は太らせない。** 1行ポインタだけにして、中身は各ファイルに書く。
- **書きすぎより書かなすぎを心配する。** 「あ、それ前にも言いましたよね」と思った瞬間が書きどき。
