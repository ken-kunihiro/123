# 第9回の配布物（追加）：freee人事労務 年調一覧表ボタン（Chrome拡張）

畠山式AI税理士ブートキャンプ **第9回**の年末調整パートに関連する追加配布物です。
freee人事労務（https://p.secure.freee.co.jp/ ）の年末調整の画面に「年調一覧表」ボタンを追加します。

| フォルダ | できること |
|----------|-----------|
| `freee-nencho-ichiran/` | 従業員全員の年末調整の計算結果を1枚の一覧表にして、CSV／Excel貼り付け用／PDFで出力（freee申告の「年末調整データ一覧表」と同じ数字が並びます） |

**前提：freee人事労務を契約していて、Chromeで使っている方向けです。**
freee人事労務を使っていない方は、この配布物はスキップして大丈夫です。

## これは何をするもの？

freee人事労務で年末調整を進めると、従業員ごとの計算結果は画面で1人ずつしか見られません。
この拡張は、年末調整の画面にボタンを1つ足して、**全従業員の給与収入・各種控除・年調年税額・過不足額（還付/徴収）を1枚の一覧表**にします。

- 年調ソフトに入力した結果の**全体チェック（レビュー）用の一覧**として使えます
- 顧問先への報告資料（PDF）としてそのまま出せるレイアウトにしてあります
- 過不足額はマイナス＝還付です。一覧の上部に過不足額の合計も出ます

## 入れ方

1. Chromeで `chrome://extensions` を開く（Braveは `brave://extensions`）
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `freee-nencho-ichiran` フォルダを選ぶ
5. freee人事労務の年末調整の画面を開くと、画面上部に「🌸 年調一覧表」ボタンが出ます（ボタン列がない画面では右下にフローティングで出ます）

> フォルダ名が英語のままなのは、Chromeに読み込ませるときに日本語のフォルダ名がトラブルの原因になることがあるためです。変更しないでください。

うまく入らないときは、画面のスクリーンショットをClaude Codeに貼って相談すれば案内してくれます。

## 使い方

1. freee人事労務にログインし、年末調整の画面を開く
2. 「🌸 年調一覧表」ボタンを押す → 従業員一覧と各人の計算結果を自動で集めて一覧表を表示します
3. 出力は3種類
   - **📥 CSVダウンロード**：Excelでそのまま開ける形式です
   - **TSVコピー**：開いているExcelに直接貼り付けたいときに使います
   - **🖨 PDF出力**：印刷ダイアログが開くので、保存先で「PDFに保存」を選んでください。A4横向き・2シート構成（①税額サマリー／②所得控除の内訳）で、法人名・合計行つきです

- 対象年は画面のURLから自動判定します（年をまたいで違う年が出たら、年末調整の画面で対象年を開き直してください）
- **年調対象外の従業員は給与収入だけ表示し、年調計算の列は空欄**になります（freee申告の「年末調整データ一覧表」と同じ見え方です）
- freee申告側の「年末調整データ一覧表」と人数が合わない場合は、freee申告⇔人事労務の**連携対象の設定**を確認してください（この拡張は人事労務にいる全従業員を出します）

## 安全設計

- **読み取り専用**。freeeへの書き込みは一切しません（データを書き換えるAPIは呼びません）
- **外部への送信はゼロ**。通信先はfreee人事労務のサイトだけです
- 読み取ったデータの保存先は**このPCのChrome内だけ**（`chrome.storage.local`）

## 注意

- freee側の画面やAPIが変わると動かなくなることがあります。その場合は講義でお知らせします
- 金額はfreee人事労務が内部に持つ源泉徴収簿のデータをそのまま並べたものです。**計算の当否の判定や税務判断はこの拡張は行いません**。最終チェックは今までどおりご自身（税理士）が行ってください
- 年末調整のデータは個人情報のかたまりです。出力したCSV・PDFの保管場所には十分ご注意ください（GitHubのリポジトリにアップロードしない・Discordに貼らない、を徹底してください）
