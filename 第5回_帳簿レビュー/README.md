# 第5回：帳簿レビュー（記帳自動化を「レビューできる仕組み」に育てる）

第3回で「起票の自動化」をやりました。第5回はその続きで、
**起票された帳簿をAIに税理士の目でチェックさせる**体験と、
そのチェックを**自分のスキルに育てる**体験をします。

進め方の本体は課題ページ（ブートキャンプでご案内しているURL）です。
このフォルダには、課題ページから使う材料一式が入っています。

## 2つの体験ルート

どちらでも同じ体験ができます。**迷ったらBから**が安全です。

### ルートA：自分の事業所でやる

freee／MF会計のMCP（または仕訳帳CSVのエクスポート）を使って、
自分の会社・テスト用の事業所をレビューします。第3回のセットアップが済んでいる方向けです。

### ルートB：デモ帳簿でやる

会計ソフトにつなぎません。同梱の `デモ帳簿_株式会社デモテック.xlsx` を
Claude Codeに読ませてレビューします。**架空の会社なので、何をどう間違えても安全**で、
答え合わせまでできます。各プロンプトの「B. デモ帳簿版」を使ってください。

## 大事な前提：このデモには請求書がありません

実務のレビューでは、指摘の多くが「請求書・通帳・相手への確認」につながります。
デモ帳簿には証憑がないので、そうした指摘は**「確認リストを作るところまで」がゴール**です。

これは手抜きではなく、実務と同じ型です。AIが確認リストを作り、
人がリストを持って証憑を開く。**リストが作れた時点で、レビューの仕事の半分は終わっています。**
詳しくは `デモ帳簿の答え合わせ.md` の「今日できること」の列を見てください。

## 安全のお願い

- 自分の事業所のレビュー結果（月次レビュー_YYYYMM.md 等）には取引先名や金額が入ります。
  **GitHubのリポジトリにアップロード（コミット）しない（非公開リポジトリでも同じ）・掲示板に貼らない**でください
- AIの指摘は「気づき」です。**直すかどうかの最終判断・税務判断は必ず人**が行ってください。
  事務所職員の方は、所内の税理士に確認してから直してください
- 顧問先の本番データで税区分を直すときは、必ず修正前後の一覧を残してください
