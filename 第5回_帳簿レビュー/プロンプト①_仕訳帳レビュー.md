# プロンプト①：仕訳帳レビュー（10観点）

課題ページ ステップ③で使うプロンプトです。2種類あります。

- **A. 自分の事業所版**：freee／MF会計につないで、自分（自社・テスト事業所）の帳簿をレビューします
- **B. デモ帳簿版**：会計ソフトにつながず、このフォルダの `デモ帳簿_株式会社デモテック.xlsx` をレビューします

顧問先や自社のデータを使えない方・まずお手本で練習したい方は、Bから始めてください。
使い方はどちらも同じで、下の枠内を**そのままClaude Codeに貼り付ける**だけです。

---

## A. 自分の事業所版（freee MCP）

```
freee MCPを使います。最初に、いま接続されている事業所名を確認して見せてください。
私が「その事業所でOK」と言ってから、次に進んでください。

OKと言ったら、今月（私が別の月を指定したらその月）の仕訳・試算表を取得して、
次の10観点で月次レビューをしてください。

1. 資産科目（現金・預金・売掛金など）にマイナス残高がないか
2. 現金残高が不自然に大きくないか・動きが不自然でないか
3. 同日・同額・同摘要の重複仕訳がないか
4. 売掛金で3ヶ月以上消込のない相手先がないか
5. 同じ相手先の仕訳で、月によって勘定科目がブレていないか
6. 計上月と取引の月がズレていそうな仕訳がないか（期ズレ）
7. 役員貸付金・仮払金・仮受金に滞留している残高がないか
8. 雑費が経費全体に対して多すぎないか
9. 飲食系の仕訳が金額基準（1万円以下=会議費／超=交際費）と合っているか
10. 外注報酬・士業報酬の支払で、源泉所得税の預り金が立っているか

結果は観点ごとに「判定（OK／要確認）／該当仕訳（日付・摘要・金額）／
そう判断した理由」の表にして、要確認の分だけ最後にまとめ直してください。
レポートは「事実 → 解釈 → 確認事項」の順で、
月次レビュー_YYYYMM.md というファイルに保存してください。

大事なルール：
- あなたは「気づき」を挙げる係です。正しいかどうかの税務判断はしないでください
- 修正はまだ実行しないでください。直し方の提案までにとどめて、
  私が「この仕訳を直して」と指定したものだけ、1件ずつ直してください
```

**MF会計の方**：1行目を「MF会計（マネーフォワード クラウド会計）のMCPを使います」に変えるだけです。
仕訳帳をCSVでエクスポートしてClaude Codeに読ませる方法でもOKです（どの会計ソフトでも使える、いちばん汎用的なやり方です）。

## B. デモ帳簿版（Excelを読ませる）

```
このフォルダにある「第5回_帳簿レビュー/デモ帳簿_株式会社デモテック.xlsx」を
読んでください（架空の会社の1年分の帳簿です。シートは
概要・仕訳帳・試算表・月次推移の4枚あります）。

読めたら、この帳簿を次の10観点で年次レビューしてください。
対象期間は帳簿の全期間（2025年8月〜2026年7月）です。

1. 資産科目（現金・預金・売掛金など）にマイナス残高がないか
   （試算表の期末残高だけでなく、期首残高＋仕訳の積み上げで期中の推移も見る）
2. 現金残高が不自然に大きくないか・動きが不自然でないか
3. 同日・同額・同摘要の重複仕訳がないか
4. 売掛金で3ヶ月以上消込のない相手先がないか
5. 同じ相手先の仕訳で、月によって勘定科目がブレていないか
6. 計上月と取引の月がズレていそうな仕訳がないか（期ズレ）
7. 役員貸付金・仮払金・仮受金に滞留している残高がないか
8. 雑費が経費全体に対して多すぎないか
9. 飲食系の仕訳が金額基準（1万円以下=会議費／超=交際費）と合っているか
10. 外注報酬・士業報酬の支払で、源泉所得税の預り金が立っているか
    （預り金の残高は期首残高から積むこと。期中の増減だけで見ると
    前期からの未納分を見落とします）

結果は観点ごとに「判定（OK／要確認）／該当仕訳（日付・摘要・金額）／
そう判断した理由」の表にして、要確認の分だけ最後にまとめ直してください。
レポートは「事実 → 解釈 → 確認事項」の順で、
デモ帳簿レビュー.md というファイルに保存してください。

大事なルール：
- あなたは「気づき」を挙げる係です。正しいかどうかの税務判断はしないでください
- このデモ帳簿には、請求書などの証憑がありません。証憑を見ないと結論が
  出ない指摘は、結論を出さずに「何を確認すべきか」の確認リストに
  とどめてください
```

レビューが終わったら、`デモ帳簿の答え合わせ.md` と見比べてください。
この帳簿には**わざと間違いを仕込んであります**。全部拾えましたか？

## 練習が終わったら

うまく動いたプロンプトは、あなたの事務所の「型」の原型です。
`レビュー観点表.md` から観点を足したり、金額基準を自社ルールに書き換えたりして、
自分用のレビュープロンプトに育ててください（課題ページ ステップ⑤）。

> **ご注意**：自分の事業所版のレビュー結果ファイルには取引先名や金額が入ります。
> GitHubのリポジトリにアップロード（コミット）したり（非公開リポジトリでも同じ）、掲示板に貼ったりしないでください。
