# 帳簿レビュー観点表（43観点）

この表は、畠山が顧問先の月次レビューで実際に使っている観点マスタ（138観点）から、
ブートキャンプ用に43観点を抜き出したものです。

課題ページのステップ③（10観点）・ステップ④（6観点）は、この表の中から
「最初に押さえるべきもの」を選んだ入門セットです。慣れてきたら、この表から
観点を足して、自分のレビュー用プロンプトを育ててください。

## この表の読み方

| 列 | 意味 |
|----|------|
| 層 | **L1** = 帳簿データだけで機械的に検出できる ／ **L2** = AIが候補を出し、人が確認する ／ **L3** = **AIに判定させない**。必ず税理士が判断する |
| 重要度 | **要訂正** = 見つけたらほぼ確実に直すもの ／ **要確認** = 事情を確かめてから判断するもの ／ **参考** = 傾向として知っておくもの |

## 大事な前提：指摘には2種類あります

AIレビューの指摘は、次の2つに分かれます。この区別がレビューの品質を決めます。

1. **帳簿の中だけで白黒がつくもの**（重複仕訳・資産のマイナス残高・科目ブレなど）
   → その場で直せます。
2. **請求書・契約書・通帳などの証憑を見ないと結論が出ないもの**（期ズレ・修繕費か資本的支出か・源泉徴収の要否など）
   → AIの仕事は「**確認リストを作るところまで**」です。リストを持って証憑を開き、
   最終判断するのは人（税理士）です。AIに証憑なしで結論を出させないでください。

L3の観点はさらに厳格で、証憑があってもAIには判定させません。「判断材料を並べて、税理士に渡す」までがAIの仕事です。

## 自分の観点を足すには

行を1行足すだけです。ID は自由（例: MY-001）。「なぜ見るか」を必ず書いてください。
理由が書けない観点は、AIも正しく使えません。

例:

| ID | 観点 | 層 | 重要度 | なぜ見るか |
|----|------|----|-------|----------|
| MY-001 | 〇〇業の売上に△△が混ざっていないか | L1 | 要確認 | （実務でヒヤッとした理由をここに） |

| ID | 観点 | 層 | 重要度 | なぜ見るか |

| BS-004 | 現金残高の過大 | L1 | 要確認 | 「帳簿上だけ現金がある」は税務調査の典型的な指摘。実在しない現金は役員貸付金と認定され、 認定利息の課税まで連鎖する。規模に対して過大かで見るので固定300万ではなくM連動にした。 |
| BS-005 | 期中の現金・預金マイナス残高 | L1 | 要訂正 | 期末残高だけ見ると正常でも、期中でマイナスになっていれば必ずどこかが間違っている。 月末だけを見る点検では絶対に見つからない、日次の残高推移を見る観点。 |
| BS-006 | 預金の帳簿残高と外部証拠の不一致 | L1 | 要訂正 | BSで唯一「外部証拠と1円まで突合できる」科目。ここが合っていない帳簿は他も信用できない。 逆にここが合っていれば、現預金を経由した取引の網羅性はかなり担保される。 |
| BS-007 | 仮払金・仮受金の期末残存 | L1 | 要確認 | 仮勘定は「内容が分からないもの置き場」。決算に残ると内訳書に書けず、調査で必ず内容を聞かれる。 |
| BS-011 | 預り金の月次消込（BS側の見方） | L1 | 要確認 | 預り金の膨張は「納付漏れ」のサイン。源泉所得税の納付漏れは不納付加算税（10%）が即発生する。 納期特例（半期納付）の会社は6ヶ月分溜まるのが正常なので、プロファイルと合わせて判定する。 |
| BS-013 | 役員貸付金の残高・増加 | L2 | 要確認 | 役員貸付金は金融機関の評価を大きく下げ、税務上も認定利息の課税対象。 増え続けている場合は「実質的な役員報酬」と見られるリスクがある。 |
