# レビューを「スキル」にする方法（今日の総仕上げ）

プロンプトを毎回貼り付けるのは、実は仮の姿です。
Claude Codeには**スキル**という仕組みがあり、手順書を決まった場所に置いておくと、
**「帳簿レビューして」と話しかけるだけ**で同じレビューが発動するようになります。

第3回の自動記帳（「体験①をやりたい」で動いたあれ）もスキルです。
今日は、**自分のレビュープロンプトを、自分で初めてスキルにしてみましょう**。
作業はClaude Codeがやってくれるので、作れないということはありません。

## スキルとは

| | プロンプト貼り付け | スキル |
|---|---|---|
| 使い方 | 毎回コピペする | 「帳簿レビューして」と言うだけ |
| 置き場所 | 自分のメモ帳など | `.claude/skills/帳簿レビュー/SKILL.md` |
| 観点を育てたら | 貼るたびに最新版か確認が必要 | ファイルを直せば次回から全員（自分の全セッション）に反映 |

**手順書を「頭の中」や「メモ帳」から「決まった場所」に出す。** これがスキル化の本質です。
畠山が実務で使っている帳簿チェックも、この延長線上にあります。

## 手順（貼り付け1回で完了します）

キットのフォルダを開いたClaude Codeに、次をそのまま貼り付けてください。

```
私の帳簿レビューをスキルにしたいです。

1. .claude/skills/chobo-review/SKILL.md を新しく作ってください
2. 中身は「第5回_帳簿レビュー/プロンプト①_仕訳帳レビュー.md」の
   A（自分の事業所版）の手順をベースにしてください
3. 私が今日「マイレビュー観点.md」に足した観点があれば、
   それも観点リストに組み込んでください
4. スキルの説明（description）は「freee/MF会計の仕訳帳を観点リストで
   月次レビューする。税務判断はしない」としてください
5. できあがったら、SKILL.md の中身を見せてください。
   私がOKしたら完成です

大事なルール：
- スキルには手順と観点だけを書いてください。
  事業所名・取引先名・金額などのデータは書かないでください
```

## 動作確認

新しいセッションを開いて（またはそのまま）、こう話しかけてみてください。

```
帳簿レビューして
```

事業所の確認から始まって、いつものレビューが**プロンプトなしで**動けば成功です🎉

## 育て方（ここからが本番です）

- 観点を足したくなったら：「帳簿レビュースキルに『◯◯を確認する』という観点を足して」と頼むだけです
- 金額基準を変えたいときも同じです（例：「飲食の基準を5,000円に変えて」）
- クローンで取り込んだ方は、「このスキルを自分の非公開リポジトリにコミットしてプッシュして」で
  自分のGitHubに保存できます。**コミットするのはスキルのファイルだけ**
  （レビュー結果や帳簿データは含めないでください）

> **これで、第3回の「起票の型」と今日の「レビューの型」が両方スキルになりました。**
> 起票は自動、チェックも型で回る。最後の判断だけが人の仕事です。
