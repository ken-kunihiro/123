# 第7回 業務ログで改善を可視化する

AIに任せた仕事を1行ずつ記録して、「自分の事務所がどれだけ変わったか」を数字とグラフで見えるようにする仕組みです。

講師（畠山）は2026年3月からこの方式で記録を続けていて、直近2ヶ月で約1,300件のタスクが溜まりました。月別の削減時間の推移、カテゴリ別の「AIが効いている業務」、曜日別の仕事のリズムまで、ぜんぶこのログ1ファイルから出せます。

## 仕組み

```
タスク完了 → 業務ログ/log.jsonl に1行追記（Claudeが自動でやる）
                  ↓ 溜まったら
「稼働分析して」 → 業務ログ/稼働分析.html が生成される（ブラウザで開くだけ）
```

- ログは `業務ログ/log.jsonl` にテキストで溜まるだけ。**外部送信は一切ありません**
- 分析もPCの中だけで完結します（インターネット接続不要）

## 使い方

### ステップ1: Claudeに記録の習慣を教える

キットの一番上のフォルダでClaude Codeを起動して、次を貼り付けてください。

```
今日から業務ログをつけたいです。.claude/skills/gyomu-log/SKILL.md を読んで、
これからタスクが完了するたびに、業務ログ/log.jsonl へ1行追記してください。
今日やってもらった作業があれば、さかのぼって記録してください。
```

これだけで、以後のタスク完了時にClaudeが自動で記録してくれます。

### ステップ2: 溜まったら分析する

1〜2週間記録が溜まったら、Claudeに次を貼り付けてください。

```
稼働分析して。生成されたHTMLの見どころも教えて。
```

`業務ログ/稼働分析.html` が生成されるので、ブラウザで開いてください。
右上の「📄 PDFで保存」ボタンを押すと印刷画面が開き、送信先を「PDFに保存」にすれば、表紙つきの横長スライドPDFになります（所内会議や振り返りにそのまま使えます）。

## 数字の読み方（大事）

- 「手作業なら何分」はAIの見積もりなので、**甘め（大きめ）に出ます**
- 削減◯◯時間という絶対値を成果として使うのではなく、**傾向**を見てください
  - 月別の推移: AIに任せる量が増えているか
  - カテゴリ別の構成: どの業務でAIが効いているか（レバレッジが低い業務が次の仕組み化候補）
  - 記録の少ない週: AIに頼めていない週はどこか

## 安全ルール

- **taskやoutcomeに顧問先の実名を書かない**。「顧問先A」「建設業のお客様」のようにぼかしてください（ログはただのテキストファイルなので、書いた内容はそのまま残ります）
- 金額・マイナンバー等の機微情報も書かないでください
- `業務ログ/` フォルダは `.gitignore` で除外済みです。もしこのキットを自分のGitHubに上げても、ログは公開されません

## うまくいかないとき

- 「log.jsonlが見つからない」と言われた → まだ記録が0件です。ステップ1から始めてください
- グラフが1本しかない → 記録期間が短いだけです。続ければ増えます
- Claudeが記録を忘れる → 「業務ログへの追記を忘れないで」と一言リマインドすればOK。何度も忘れる場合はキット直下の `CLAUDE.md` に記録ルールが書いてあるか確認してください
