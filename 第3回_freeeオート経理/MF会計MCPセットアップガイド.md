# MF会計 MCPセットアップガイド

畠山式AI税理士ブートキャンプ 第3回の配布資料です。
マネーフォワード クラウド会計の公式MCPサーバーをClaude Codeに接続する手順をまとめます。

所要時間の目安は15分です。インストール作業はありません。
やることは3つだけです。

1. MF側の「アプリポータル」での事前設定（最初の1回だけ）
2. Claude Codeへの接続の登録（コピペ1回）
3. ブラウザでのログインと許可

## MCP連携とは

MCP（Model Context Protocol）は、AIとアプリをつなぐ共通の工し込み口です。
接続すると、Claude Codeがあなたの代わりにMF会計のデータを読み書きできるようになります。

MF公式のMCPサーバーは**リモートMCP**という方式です。自分のPCに何かをインストールするのではなく、マネーフォワード側のサーバーに「このAIからのアクセスを許可する」と登録する形です。

アップデートにより、**データ連携で取り込まれた未仕訳明細をAIが直接取得して、計上まで進められる**ようになりました。第3回の体験①はこれを使います。

## 事前に用意するもの

| 用意するもの | 補足 |
|---|---|
| マネーフォワード クラウド会計のアカウント | 全プランでMCPを利用できます |
| Claude Codeデスクトップアプリ | 第1回でセットアップ済みのもの |

## ステップ0：体験に使う「事業者」を決める

MF会計のMCP連携は、**事業者（事業所）ごとに設定と認証を行う**仕組みです。

- 当日は**ご自身の事務所の事業者か、テスト用に作った事業者**を使ってください
- 顧問先の本番事業者は使いません。顧問先側の全権管理者による事前設定が必要なうえ、本番データのため体験には不向きです
- 接続は**1事業者単位**です。別の事業者に切り替えたいときは、MF側で認可をやり直します（このガイド末尾の「よくある質問」参照）

## ステップ1：アプリポータルで「アプリ連携権限」を付ける（最初の1回だけ）

MF側の事前設定です。これをしないと、後の認証で先に進めません。

この設定ができるのは、その事業者で**「全権管理」権限を持つユーザー**だけです。ご自身の事務所やテスト用事業者なら、通常はご自身が全権管理者なのでそのまま進められます。

1. ブラウザで [アプリポータル](https://app-portal.moneyforward.com/) を開き、「マネーフォワード IDでログイン」する
2. 体験に使う事業者の「選択」をクリックする（「連携中アプリ」の画面が開けばOK。初回はここでアプリポータルの利用が始まります）
3. 左メニューの「ユーザー」から、連携操作を行うユーザー（ご自身）をクリックする
4. 「ユーザー情報」画面の右上「編集」を押し、「アプリ連携権限」の**「アプリ連携」と「クラウド会計・確定申告」の両方にチェック**を入れて「保存」する

「設定を保存しました。」と表示されたら事前設定は完了です。

※ マネーフォワード側の画面や項目名は更新されることがあります。このガイドと違う画面が出たら、画面の案内とMF公式ヘルプを優先してください。

## ステップ2：Claude Codeに接続を頼む（コピペ）

Claude Codeデスクトップアプリで、次をそのまま送信します。

```
マネーフォワード クラウド会計の公式MCPサーバー（リモートMCP）を
Claude Codeに接続してください。接続先URLは次のとおりです。
https://beta.mcp.developers.biz.moneyforward.com/mcp/ca/v3

設定できたら、ブラウザでの認証（ログインと許可）に進めてください。
私がブラウザで操作すべき場面が来たら、何をすればよいか教えてください。
認証では、体験に使う事業者（自分の事務所またはテスト用）を選びます。
```

## ステップ3：ブラウザでログインして許可する

途中でブラウザが開き、マネーフォワードのログイン画面が表示されます。

1. **自分のマネーフォワードIDでログイン**します（IDやパスワードをチャットに貼らないこと。入力は必ずブラウザ側で行います）
2. 対象の**事業者**を選ぶ画面が出たら、ステップ0で決めた事業者を選びます
3. 「アクセスを許可しますか」という確認画面が出たら、内容を読んで**許可**します

## ステップ4：新しいセッションを開いて動作確認（コピペ）

**認証が終わったら、Claude Codeをいったん開き直してください。**
接続した直後の画面のままだと、MFのツールが読み込まれず「接続したのに使えない」状態になることがあります。

新しいセッション（新しいチャット）を開いて、次を送信します。

```
マネーフォワード クラウド会計のMCPで、いま接続されている
事業者の情報を取得して見せてください。
体験に使うつもりの事業者と一致しているかを確認したいです。
```

体験に使う事業者の名前が返ってくれば、接続完了です。
違う事業者が返ってきた場合は、認証時に選んだ事業者が違います。「よくある質問」の切り替え手順でやり直してください。

## 接続すると何ができるか（第3回で使うもの）

| できること | 第3回での使い方 |
|---|---|
| 未仕訳明細の取得 | 体験①で、データ連携に溜まった明細をAIが読み取る |
| 仕訳の計上 | あなたが承認した明細だけを計上する |
| 仕訳・残高の参照 | 計上結果の確認、二重計上チェック |

## 安全のための決めごと

- **承認してから計上**：AIが判定しても勝手には計上させません。「計上前に必ず表を見せて、私の承認を待ってください」の一文を消さないこと
- **少額・少件数から**：最初は5件以内で試すこと。本番の事業者でいきなり全件処理をしないこと
- **計上後は画面で確認**：MF会計の画面で該当明細の状態を見て、同じ取引を二重計上していないか確かめること
- **ログイン情報は渡さない**：認証は必ずブラウザで行い、ID・パスワードをチャットに書かないこと

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 接続したのにMFのツールが使えない | いちばん多いパターンです。Claude Codeで**新しいセッション（新しいチャット）を開き直して**から、もう一度試す |
| 認証の途中で止まる・「権限がありません」系のエラー | ステップ1のアプリ連携権限（「アプリ連携」と「クラウド会計・確定申告」の両方のチェック）が付いているか確認する。付けられない場合は、その事業者の全権管理者に依頼する |
| ブラウザの認証画面が開かない | Claude Codeに「MF会計MCPの認証画面が開きません。もう一度認証からやり直してください」と伝える |
| 接続が切れた・急にエラーになる | 「MCPの接続状態を確認して、再認証の手順を案内して」と伝える。エラー文をそのまま貼るのが早い |
| 未仕訳明細が0件と言われる | MF会計の画面で、口座のデータ連携と明細の取得ができているか確認する |

エラー文をそのままClaude Codeに貼り付けて「これを直したい」と聞くのが、いちばんの近道です。

## よくある質問

**Q. 別の事業者に切り替えたいときは？**
接続は1事業者単位です。切り替え先の事業者でステップ1（アプリ連携権限）を済ませたうえで、Claude Codeに「MF会計MCPの認証をやり直したいです。再認証の手順を案内してください」と伝え、認証時に切り替え先の事業者を選んでください。認証後は新しいセッションを開き直します。

**Q. 顧問先の事業者で使いたいときは？**
顧問先側の全権管理者に、ステップ1と同じアプリ連携権限の設定をしてもらう必要があります。まずはご自身の事業者で十分に慣れてから、顧問先と相談のうえ広げてください。
