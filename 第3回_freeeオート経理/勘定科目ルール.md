# 勘定科目ルール（ひな形）

畠山式AI税理士ブートキャンプ 第3回の配布資料です。
未処理明細（未仕訳明細）の勘定科目を判定するための「ルール表」のひな形です。
freee会計・マネーフォワード クラウド会計のどちらでも使えます。

## AIへの指示（このファイルを読んだAIは、ここに従ってください）

明細を1件ずつ、必ず次の順で判定すること。

1. **NGキーワードに当たる** → 判定は「要確認」。登録・計上の対象から外す
2. **ルール表のキーワードに一致** → その勘定科目にする（判定元＝ルール）
3. **どれにも当たらない** → 勘定科目の候補と理由を考える（判定元＝AI）

そして、**人が「OK」と承認した明細だけ**を登録・計上すること。承認前に登録しない。

## NGキーワード（自動登録しない明細）

次のキーワードを含む明細は、内容にかかわらず「要確認」にする。
給与・税金・借入・保険は、金額や契約形態で処理が変わるため人が判断する。

```
給与, 給料, 賞与, 役員報酬, 社会保険, 年金, 健康保険, 雇用保険,
所得税, 住民税, 法人税, 消費税, 源泉, 国税, 都税, 県税, 市税, 税務署,
借入, 返済, ローン, 融資, 保証料, 生命保険, 振込 個人名のみ
```

## このルール表の育て方（体験の核心）

1. 今日「判定元＝AI」になった明細を確認する
2. その明細のキーワードと勘定科目を、上の表に**1行追加**する
3. 次回から、同じ明細はAIに聞かずルールで即決まる

これを繰り返すと、AIの出番が減り、速く・安く・ブレない自動記帳に育ちます。
「AIが間違えた」ときこそチャンスです。正しい科目をその場で直し、ルールとして書き残してください。

## 注意（このひな形の前提）

- 科目・金額基準は一般的な例です。**自社・顧問先の勘定科目体系と税理士の方針に合わせて書き換えてください**
- 税区分（課税・不課税・対象外など）はこの表では扱いません。登録時に各ソフトの初期設定に従い、迷うものは「要確認」にしてください
- 最終判断は人（税理士・経理担当）が行います。この表もAIの判定も「候補」です
